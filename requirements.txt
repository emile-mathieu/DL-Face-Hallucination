*Dataset requirement*
CelebA must already exist locally under --data_root in torchvision’s expected structure.
Your code mostly uses download=False, so missing dataset will fail.
Typical expected path pattern:
<data_root>/celeba/img_align_celeba
plus CelebA annotation files
